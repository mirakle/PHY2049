1.AC circuits

Course convention. Source voltage ε ( t ) = ε 0 cos ⁡ ( ω t ) and total current I ( t ) = I 0 cos ⁡ ( ω t − φ ) .

  • φ > 0 : the current trails the voltage.
  • φ < 0 : the current leads the voltage.
  • φ = 0 : the current is in phase with the voltage (resonance).

Memory aid: “ELI the ICE man.” In an inductor (L) the voltage E comes before the current I; in a capacitor (C) the current I comes before the voltage E.

b.One component: resistor, capacitor or inductor

With a single component, the impedance is that component’s own opposition, and the phase shift is 0 or ± π / 2 .

Phasors

A phasor is a rotating arrow whose length is a peak value; all phasors rotate counterclockwise together at ω . Draw the current I along the horizontal axis and place each voltage relative to it:

  • V R is in phase with I .
  • V L is 90 ∘ ahead of I (rotated counterclockwise).
  • V C is 90 ∘ behind I (rotated clockwise).
Check yourself: a capacitor alone

A 50.0   μ F capacitor is connected to a source with ε 0 = 120   V and f = 60.0   Hz . Find the peak current and say whether it leads or trails.

X C = 1 2 π f C = 1 2 π ( 60.0 ) ( 50.0 × 10 − 6 ) = 53.1   Ω , so I 0 = ε 0 X C = 120 53.1 = 2.26   A . The current leads the voltage by 90 ∘ .

c.Two components: RC or RL

HINT: Start with the most general case, Z = R 2 + ( X L − X C ) 2 , and remove the parts that are not in your circuit. For an inductor alone, drop R and X C to get Z = X L .

Impedance and phase shift with two components in series
CircuitImpedance Z Phase shift φ Current versus source voltage
R and C Z = R 2 + X C 2 φ = tan − 1 ( − X C R ) Current leads ( φ < 0 )
R and L Z = R 2 + X L 2 φ = tan − 1 ( X L R ) Current trails ( φ > 0 )

In a series circuit the same current flows through every component, so I is the reference phasor. The source phasor ε 0 is the vector sum of the component phasors, so peak voltages do not simply add: for RC, ε 0 = V R 2 + V C 2 ; for RL, ε 0 = V R 2 + V L 2 .

Check yourself: an RL circuit

R = 40   Ω and L = 0.10   H are in series with a source at ω = 300   rad / s . Find Z and φ .

X L = ω L = 30   Ω . Z = 40 2 + 30 2 = 50   Ω . φ = tan − 1 ⁡ ( 30 / 40 ) = 36.9 ∘ : positive, so the current trails the source by 36.9 ∘ .

d.Low-pass and high-pass filters

A filter takes its output across one component. The output is large when that component has a large share of the impedance.

Where to take the output for each filter
CircuitLow-pass: output acrossHigh-pass: output acrossCrossover frequency

At the crossover frequency the reactance equals the resistance ( X C = R or X L = R ), and the output is 1 / 2 ≈ 0.707 of the input.

Check yourself: a crossover frequency

An RC filter has R = 1.0   k Ω and C = 0.10   μ F . Find f c , and say where to take the output for a low-pass filter.

ω c = 1 R C = 1 ( 1.0 × 10 3 ) ( 0.10 × 10 − 6 ) = 1.0 × 10 4   rad / s , so f c = ω c 2 π = 1.6   kHz . For low-pass, take the output across the capacitor.

e.RLC circuits and resonance

With all three components, V L and V C point in opposite directions, so they partly cancel. Their difference sets the sign of φ .

The series RLC circuit
CircuitImpedance Z Phase shift φ Current versus source voltage
RLC Z = R 2 + ( X L − X C ) 2 φ = tan − 1 ( X L − X C R ) Trails if X L > X C ; leads if X L < X C ; in phase if X L = X C

Resonance

At resonance X L = X C , so

ω 0 = 1 L C f 0 = 1 2 π L C

At resonance Z = R (its smallest value), I 0 = ε 0 / R is maximum, and φ = 0 .

Check yourself: a resonance frequency

An RLC circuit has L = 20   mH and C = 5.0   μ F . Find ω 0 and f 0 .

ω 0 = 1 ( 20 × 10 − 3 ) ( 5.0 × 10 − 6 ) = 1 1.0 × 10 − 7 = 3.16 × 10 3   rad / s , and f 0 = ω 0 / 2 π = 503   Hz .

f.Power factor

cos ⁡ φ = R Z P avg = 1 2 ε 0 I 0 cos ⁡ φ = 1 2 I 0 2 R

Only the resistor dissipates energy on average; an ideal capacitor or inductor stores energy and gives it back each cycle.

Making the power factor equal to 1: change C (or L ) so that X L = X C . For example, with L and ω fixed, use C = 1 ω 2 L .

For the RL circuit above ( R = 40   Ω , Z = 50   Ω ), what is the power factor? What capacitor, added in series, would make it 1?

cos ⁡ φ = R / Z = 0.80 . To cancel X L = 30   Ω , we need X C = 30   Ω : C = 1 ω 2 L = 1 ( 300 ) 2 ( 0.10 ) = 1.1 × 10 − 4   F = 111   μ F .

2.Magnetism

All the quantities in this section are vectors. “Calculate the field (or the force)” means: (1) compute the magnitude, and (2) find the direction with the right-hand rule. Add several fields or forces using vector addition.

Fields can only be added to fields. Never add a field to a force.

Field lines are closed loops with no beginning or end. The unit of B → is the tesla, T .

Right-hand rules

For a cross product C → = A → × B → (vector 3 = vector 1 × vector 2), the order matters. Any one of these three methods works; pick one and use it every time.

Method 3 (flat hand)stretched thumbstretched fingersperpendicular to the palm

b.Effects of magnetic fields: force on a moving charge

F → = q v → × B → , F = | q | v B sin ⁡ θ

The field comes from other sources, never from the charge itself. The magnetic force is always perpendicular to v → , so it changes the direction of motion but not the speed: it does no work.

Velocity perpendicular to a uniform field: circular motion

The magnetic force is the centripetal force, | q | v B = m v 2 R , which gives

Radius R = m v | q | B faster or heavier means a bigger circle

Velocity not perpendicular to the field: helical motion

Split v → into v ⊥ = v sin ⁡ θ (across the field) and v ∥ = v cos ⁡ θ (along the field). v ⊥ makes circles; v ∥ is unaffected and carries the circles along the field.

radius:  r = m v ⊥ | q | B pitch:  p = v ∥ T = 2 π m v ∥ | q | B

The field of another moving charge

The field acting on a charge can be the field of another moving charge. Use the point-charge field formula first, then F → = q v → × B → .

Velocity selector

With crossed E → and B → , a particle goes straight when the electric and magnetic forces balance: q E = q v B , so

v = E B

A 50-turn coil of area 0.010   m 2 carries 2.0   A in a 0.30   T field, with its plane parallel to the field. Find the torque. How much work does the field do as it turns the coil into alignment?

μ = N I A = ( 50 ) ( 2.0 ) ( 0.010 ) = 1.0   A ⋅ m 2 . Plane parallel to B → means μ → ⊥ B → , so θ = 90 ∘ and τ = μ B = 0.30   N ⋅ m .

3.Electromagnetic induction

a.Magnetic flux

Φ = B → ⋅ A → = B A cos ⁡ θ , 1   Wb = 1   T ⋅ m 2

The area vector is perpendicular to the surface, and by convention it points toward you as you look at the surface. θ is the angle between B → and A → .

b.Faraday’s law and the induced current

ε = − N d Φ d t

N is the number of loops. Since Φ = B A cos ⁡ θ , the flux can change in three ways: through B , through A or through θ .

The four cases of Faraday’s law
What changesInduced emfExample
i. Field strength ε = − N d B d t A cos ⁡ θ a magnet moving toward a coil; a current switched on in a nearby coil
ii. Area ε = − N B d A d t cos ⁡ θ a rod sliding on rails: | ε | = B l v
iii. Angle, continuously at constant ω ( θ = ω t ) ε = − N B A d cos ⁡ ( ω t ) d t = N B A ω sin ⁡ ( ω t ) an AC generator, with ε 0 = N B A ω
iv. Angle, sudden reversal ε = − N B A Δ cos ⁡ θ Δ t , so | ε | = 2 N B A Δ t a coil flipped over: cos ⁡ θ goes from + 1 to − 1

Induced current (Ohm’s law): I = | ε | R , where R is the resistance of the loop. Usually only the magnitude is needed.

Check yourself: Faraday’s law

(a) A 100-turn coil of area 0.020   m 2 and resistance 8.0   Ω faces a field that grows from 0.20   T to 0.80   T in 0.30   s ( θ = 0 ). Find | ε | and I . (b) A 0.50   m rod slides at 4.0   m / s on rails in a 0.25   T field. Find | ε | . (c) A 200-turn generator coil of area 0.010   m 2 turns at 60   Hz in a 0.40   T field. Find ε 0 .

(a) | ε | = N A Δ B Δ t = ( 100 ) ( 0.020 ) 0.60 0.30 = 4.0   V , and I = 4.0 8.0 = 0.50   A .

(b) | ε | = B l v = ( 0.25 ) ( 0.50 ) ( 4.0 ) = 0.50   V .

(c) ω = 2 π ( 60 ) = 377   rad / s , so ε 0 = N B A ω = ( 200 ) ( 0.40 ) ( 0.010 ) ( 377 ) = 302   V .

c.Reading graphs

The emf is the negative of the slope of the Φ versus t graph (or − N A times the slope of the B versus t graph).

  • A positive slope gives a negative emf; a negative slope gives a positive emf.
  • A flat segment gives zero emf, even if the flux is large.
  • A steeper slope gives a larger | ε | .

d.Direction of the induced current: Lenz’s law

The induced current makes a field that opposes the change in flux. It does not oppose the flux itself.

  1. Choose the area vector toward you and find the sign of Φ .
  2. Find the sign of d Φ d t . The emf has the opposite sign.
  3. If ε > 0 the current is counterclockwise as you see it; if ε < 0 it is clockwise.

Force check: a magnet approaching a coil is repelled (the near face of the coil becomes the same pole as the approaching pole). A magnet moving away is attracted.

Check yourself: Lenz’s law

A loop lies flat on the page in a field pointing into the page. The field is switched off. Which way does the induced current flow, as seen from above the page?

With A → toward you, Φ < 0 (the field is away from you). As the field dies, Φ rises from negative toward zero, so d Φ / d t > 0 and ε < 0 : the current is clockwise. Check: a clockwise current makes a field into the page, replacing the field that is disappearing.
